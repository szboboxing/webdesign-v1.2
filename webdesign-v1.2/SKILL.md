# webdesign v1.2 — 暖色系单页设计系统（配色规范）

一套以「三文鱼粉 + 酒红」为核心的暖色系单页设计系统。全篇**只使用一种强调色（酒红 #990F3D）**，所有白色改为暖白、所有纯黑改为近黑，长分割线改为居中小短横。

## 何时使用
- 用户要求按"三文鱼粉 + 酒红"配色美化 HTML 页面、文档或卡片。
- 需要产出**配色规范说明 / 设计系统文档**。
- 需要一套可复制粘贴的设计令牌（Token）与 CSS。

## 设计令牌（Token）
完整 CSS 见 `references/design-system.md`。核心令牌：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面底色 | `#FFF1E5` | 三文鱼粉，非纯白 |
| 卡片底色 | `#FFFAF6` / `#FFE7D6` | 暖白 / 浅蜜桃，均与底色同色系 |
| 输入框 / 代码区 | `#FFFDFB` | 暖白，非纯白 |
| 强调弱化底 | `#FBE3E9` | 酒红极淡晕染 |
| 描边 | `#F0DCCC` | 暖棕调，避免冷灰 |
| 正文文字 | `#33302E` | 近黑非纯黑 |
| 次要文字 | `#8C7F74` | 同色系弱化 |
| **唯一强调色** | `#990F3D` | 酒红，全篇只此一色 |

## 主题切换（默认组件）
套用本规范的所有页面/文档，**默认在页头右上角加入三态主题切换按钮：`跟随系统 / 明亮 / 昏暗`**，状态写入 `localStorage`。暗色令牌与切换控件 CSS/JS 见 `references/design-system.md` 的「主题切换」一节。暗色下强调色微调为更可读的 `#C7365F`（仍只此一色）。

## 排版规范
- 正文 `16px`、行距 `1.85`。
- 小标题 `17px` 加粗 + 左侧 `4px` 酒红竖线（`.card-title`）。
- Markdown 内 `**加粗**` 用酒红；链接、四级以下小标题也用酒红。
- 分割线**只画一小截**：宽 `48px`、高 `3px`、居中、酒红（`hr.divider`）。

## 组件范式
- **卡片**：暖白底 + 暖描边 + 极淡酒红阴影 `0 2px 10px rgba(153,15,61,.06)`。
- **小标题 `.card-title`**：`border-left:4px solid #990F3D; padding-left:12px`。
- **短分割线 `<hr class="divider">`**：`width:48px;height:3px;background:#990F3D;border-radius:2px;margin:10px auto 24px`。
- **主按钮**：酒红实底白字；次按钮：暖白底 + 暖描边。
- **状态徽标**：完成态酒红实底；失败态同色系加深 `#6E0B2C`；规避第二种鲜艳色。

## 配色禁忌
- 不要出现第二种鲜艳强调色（绿 / 蓝 / 橙等）。
- 不要用 `#ffffff`、冷灰 `#f6f7f9` 作底色。
- 不要用 `#000000`、冷黑 `#24292f` 作正文。
- 不要用通栏长分割线；重点分隔只用 48px 短横。

## 复用口诀
只保留酒红一种强调色；所有白底改暖白；纯黑改 `#33302E`；长分割线改 48px 短横；小标题统一加酒红竖线。
