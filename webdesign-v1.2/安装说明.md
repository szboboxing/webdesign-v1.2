# webdesign v1.2 · 安装与使用说明

暖色系单页 Web 配色设计规范（三文鱼粉 `#FFF1E5` + 酒红 `#990F3D` + 正文 `#33302E` / 16px / 行距 1.85），
附带三态主题切换（跟随系统 / 明亮 / 昏暗）、酒红竖线小标题、48px 短分割线等组件范式。

## 一、安装到 WorkBuddy

1. 把 `webdesign-v1.2/` 整个目录复制到用户级 skills 目录：
   `C:\Users\<你的用户名>\.workbuddy\skills\webdesign-v1.2\`
   （macOS / Linux 路径为 `~/.workbuddy/skills/webdesign-v1.2/`）
2. 重启 / 刷新 WorkBuddy 对话，使技能清单生效。
3. 验证：在对话中输入"按 webdesign 暖色系美化这个页面"之类，应触发本 skill。

> 也可把本目录复制为项目级 skill：放在当前工作区的 `.workbuddy/skills/webdesign-v1.2/` 下，仅对当前项目生效。

## 二、使用前的关键约定（必读）

`安装提示词.txt` 已写明：**以后生成 HTML 格式的页面，必须先询问是否应用本 skill 再动手。**
即默认不要在每次 HTML 产出时自动套用；先确认用户是否要走暖色系规范，避免对不适用场景（如后台管理、数据大屏）强行套用。

## 三、套用时做什么

- 复制 `references/design-system.md` 里的 `:root` 令牌 + 基础样式 + 主题切换代码到页面 `<style>` / `<head>`。
- 在页头右上角加入三态主题切换按钮（HTML + JS 见 design-system.md「主题切换」一节），并 `localStorage` 持久化。
- 组件范式：卡片暖白底 + 暖描边 + 极淡酒红阴影；小标题加酒红竖线；分割线只用 48px 短横。
- 配色禁忌：不出现第二种鲜艳强调色；不用纯白/冷灰作底、纯黑/冷黑作正文；不画通栏长分割线。

## 四、快速参考

- 想直接看效果：浏览器打开 `assets/webdesign-v1.2.html`（活范本）。
- 想让 AI 直接套规范：复制 `assets/webdesign-v1.2-prompt.md` 全文粘贴到任意对话。
- 配色示意图：`assets/effect-showcase.svg`。
